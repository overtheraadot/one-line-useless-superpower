One original line for make.fun's "One Line, Zero Use: The Useless Superpower Sprint" bounty: a hero who knows the exact second the elevator will arrive — and has never once made it arrive sooner. A superpower that sounds great and helps nobody.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` writes the single line to `entry.txt` in the output directory (default `/output`), deterministically, with no network or model calls.
